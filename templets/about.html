ℹ️ About the Project

Android APK Botnet Detection using static feature extraction and machine learning

This project screens uploaded APK files by extracting important static indicators and using your trained classifier to decide whether the app looks benign or suspicious.

How it works

The system reads APK metadata such as permissions, Android manifest actions, file types like DEX and SO, and selected code/string traces. Those extracted values are mapped to the same feature order used during training and passed to the saved SVM model.

Why static analysis

Static analysis is fast and practical for academic and demo projects. It helps identify risky behavior before installation, though it is not a replacement for full sandbox or dynamic malware analysis.
